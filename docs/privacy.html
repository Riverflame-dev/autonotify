Privacy Policy

Last updated: September 15, 2026

Scope

autonotify is a personal tool operated by a single individual for their own Gmail account. It has no other users and collects no data from anyone else.

What it accesses

With the gmail.readonly scope, autonotify reads message metadata (subject, sender, snippet, date) from the operator's own mailbox, and message bodies only for the small number of messages identified as job-application updates. It never modifies, deletes, or sends mail.

Where data goes

Processing happens on the operator's own computer. Message data is not sold, shared, or transmitted to third parties, except that the text of candidate job-application emails may be sent to Anthropic's Claude for classification, and a short summary notification (company name and update type) is delivered to the operator's own phone via ntfy.sh. No message content is published.

Retention

Only message IDs already processed, and local run logs, are stored on the operator's machine. These can be deleted at any time by removing the tool's local state/ and logs/ directories.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
